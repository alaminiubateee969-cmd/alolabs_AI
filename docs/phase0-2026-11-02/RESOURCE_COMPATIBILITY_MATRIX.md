## Interpretation and common integration risks

- README keyword hits are not interface inventories. Repo-specific deployment, dependency compatibility, authentication, APIs, CPU/RAM/VRAM and local inference must be verified against pinned versions before integration. No dependency vulnerability scan was run.
- Executable code, binaries, agents, web content and third-party plugins are untrusted. Use disposable isolated environments, no production secrets, tight egress and explicit approval for privileged effects.
- Voice/video/model workers require model-weight and training-data licences, consent and measured disk/RAM/VRAM; none were benchmarked. Open-source code does not imply free hosted providers, hardware, email/SMS delivery or unrestricted model weights.
- The `A` recommendations describe already-present instruction-only guidance, not approval of upstream scripts, external services, or tool privileges. Even those instructions require prompt-injection and per-file licence review.
- None of the F resources should be implemented or represented as cleared until their access, terms and safety are established.
